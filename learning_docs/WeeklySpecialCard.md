# WeeklySpecialCard

## Purpose / Responsibility
The `WeeklySpecialCard` is a UI component used as a header for the "Weekly Special" section of the menu list. It provides a clear visual anchor for users to identify where the specials begin.

## Input Parameters
- None.

## How it works within the UI
It is placed at the very top of the `LowerPanel`. In the current implementation, it uses a `Column` with horizontal and vertical padding to create a spacious and clean section title. 

## Simple Explanation
This is like a **Section Header** in a physical menu. It simply says "Weekly Special" in a large, bold font to catch the user's eye and tell them that the items following this heading are the restaurant's highlights for the week.
