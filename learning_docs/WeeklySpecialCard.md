# WeeklySpecialCard

## Purpose / Responsibility
The `WeeklySpecialCard` is a simple UI component used to display a header or banner for the "Weekly Special" section of the menu.

## Input Parameters
- None.

## How it works within the UI
It is placed at the top of the `LowerPanel`. It uses a Material `Card` to provide a subtle elevation and background, making the section header stand out from the individual menu items.

## Simple Explanation
This is like a "Section Header" in a physical menu. It simply says "Weekly Special" inside a nice box to tell the user that the items below are special for this week.
